# CL25-GEN — CL25-1 ⇔ CL25-2 NCプログラム相互変換ツール

NC旋盤 **CL25-1** と **CL25-2** の間でプログラムを載せ替える際の、設備固有コードの書き換えを自動化するツールです。
HTML＋バニラJavaScript のみで動作し（ライブラリ・ネット接続不要）、`index.html` をブラウザで開くだけで使えます。

> **大原則: 定義済みルールの置換のみを行い、ルール外の変換・文字削除は一切行いません。**
> 改行コード（CRLF）・空行・スペース・コメント・寸法値はそのまま保持されます。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK・オフライン動作）
2. NCプログラムを貼り付けるか、「ファイルを開く」またはドラッグ＆ドロップで読み込む
   - 機械名コメント `(CL-25-1)` / `(CL-25-2)` から変換方向を自動判定します（手動切替も可能）
3. 「変換実行」を押す
4. 変換ログ（置換件数・行ごとの変更前→変更後）と警告を確認する
   - 「逆変換一致 ✓」は、結果を逆方向に再変換すると入力と完全一致することの自己チェックです
5. 「コピー」または「保存 (.txt)」で取り出す
   - 保存ファイル名は `CL251…` ⇔ `CL252…` を自動で付け替えます
   - 改行コードは読み込んだファイルのまま保持されます（貼り付け入力時は CRLF）

## 雛形プログラムの差分まとめ

同一部品（G7/8）の CL25-1 版・CL25-2 版プログラムを比較して設備差を確定し、
別部品ペア（M22X1.5 / M18X1.5）で同じ差分パターンであることを裏付けました。

### トークン置換（双方向）

| CL25-1 | CL25-2 | G7/8 雛形内の箇所数 | 備考 |
|---|---|---|---|
| `(CL-25-1)` | `(CL-25-2)` | 1 | 機械名コメント（`CL25-1` 表記にも対応） |
| `M50` | `M51` | 12 | |
| `M55` | `M59` | 11 | |
| `M8` | `M458` | 7 | |
| `M9` | `M459` | 7 | |
| `M61` | `M53` | 1 | |
| `T0101` | `T0101M19` | 1 | CL25-2 側のみ M19 付き（1→2 で付加、2→1 で M19 削除） |
| `T0200` | `T0200M19` | 1 | 同上 |

### 構造差（行の挿入/削除）

プログラム終端のみ、CL25-2 には `M3S1`・`M5` の2行が余分に存在します。

```
CL25-1              CL25-2
T0200               T0200M19
G28U0W0             M3S1
N99                 M5
M30                 G28U0W0
                    N99
                    M30
```

- 1→2: `T0200M19` の**直後（次行が `G28U0W0` のときのみ）**に `M3S1`・`M5` を挿入
- 2→1: `T0200(M19)` / `M3S1` / `M5` / `G28U0W0` の並びのときのみ該当2行を削除
- 位置パターンが一致しない場合は**何もせず警告表示**（N6 工程中の単独 `M5` 行などには影響しません）

### 変換対象外（設備差ではないもの）

- M22/M18 ペアに見られる寸法・工具番号（例 `T0707`→`T0404`）・語順（`S750T0909`↔`T0909S750`）の違いは
  **部品プログラム差**であり、G7/8 ペアでは両設備とも同一のため変換しません
- `M0 / M1 / M3 / M5 / M30 / M99` 等の共通コードは変換しません

## 安全設計

- **数字境界ガード**: `M9` が `M99` や `M459` の一部に誤一致しない（`M5` と `M50/M55` 等も同様）
- **コメント保護**: `( )` 内はMコード置換の対象外（`(M99P100)` などは不変更。機械名コメントのみ置換）
- **一括1パス置換**: 連鎖置換（M51→M50→…のような二重変換）が起きない
- **M19 二重付加防止**: 既に `T0101M19` の行には付加せず警告
- **方向チェック**: 機械名コメント・設備固有コードから入力の設備を判定し、選択方向と食い違う場合は警告
- **逆変換一致チェック**: 変換結果を逆方向に再変換して入力と完全一致するかを毎回自動確認
- 小文字コード（`m8` 等）は変換せず、検出時に警告のみ表示

## 検証

```
node test/verify.js
```

- **黄金テスト**: 雛形 `CL251G78…` を 1→2 変換した結果が雛形 `CL252G78…` と**バイト完全一致**（CRLF含む）。逆方向も同様
- **往復テスト**: 4雛形すべて 変換→逆変換 で原文と完全一致
- ガードテスト（部分一致・コメント・途中の `M5` 行・誤方向・小文字など）、機械判定テスト
